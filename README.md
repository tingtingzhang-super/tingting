# 作品集网站 · Portfolio

一个极简、干净、响应式、零依赖、好维护的个人作品集模板。
纯 HTML / CSS / JavaScript，**没有任何构建步骤**——双击 `index.html` 就能在浏览器里看到。

---

## 特点

- **极简克制**：大留白、衬线标题、近黑配暖白、一处低调强调色。
- **响应式**：手机 / 平板 / 桌面自适应。
- **深浅色**：自动跟随系统，也可手动一键切换。
- **中英双语**：内置语言切换；不需要英文版可一行配置关掉。
- **好维护**：所有文字集中在 `content.js` 一个文件里。
- **兼容性好**：无框架、无构建，老浏览器也有兜底显示。
- **细节灵气**：滚动渐显、顶部进度条、优雅的 hover 微交互、尊重「减少动态效果」无障碍设置。

## 文件结构

```
.
├── index.html          页面骨架（一般不用动）
├── content.js          ← 你的所有内容都在这里，平时只改这个
├── assets/
│   ├── css/styles.css  外观样式（想换颜色/字号改这里的 :root 变量）
│   ├── js/main.js      逻辑（渲染、切换、动效；一般不用动）
│   └── img/            放你的作品图片
└── README.md
```

## 如何修改

### 1. 改文字内容 → 只编辑 `content.js`

打开 `content.js`，里面每段都有中文注释说明。每条内容都是
`{ zh: "中文", en: "English" }` 的形式，改对应语言即可。

- 改名字 / 标题 → `brand`、`hero`
- 改自我介绍 → `about`
- 增删作品 → `projects`（建议放 3–5 个，按「问题 → 决策 → 结果」写）
- 改联系方式 → `contact`（填邮箱、删掉不需要的社交链接）

### 2. 加作品图片

把图片放进 `assets/img/`，再到 `content.js` 对应作品的 `cover` 里填路径：

```js
cover: "assets/img/my-project.jpg",
```

不填 `cover` 也没关系，会自动显示一个优雅的占位色块。

### 3. 只要中文、不要英文

把 `content.js` 顶部改成：

```js
site: { languages: ["zh"], defaultLang: "zh", ... }
```

语言切换按钮会自动隐藏。

### 4. 换主题色 / 字号

打开 `assets/css/styles.css`，改最上面 `:root` 里的变量，比如强调色：

```css
--accent: #b1502f;   /* 改成你喜欢的颜色 */
```

## 本地预览

直接双击 `index.html` 即可。若想用本地服务器（推荐，避免个别浏览器限制）：

```bash
# 任选其一
python3 -m http.server 8000      # 然后打开 http://localhost:8000
npx serve .
```

## 部署（免费、几分钟搞定）

这是纯静态站，可部署到任意静态托管：

- **Vercel**：`npx vercel` 或在网站上拖入文件夹。
- **GitHub Pages**：推到仓库后，Settings → Pages → 选 `main` 分支根目录。
- **Netlify**：把整个文件夹拖到 netlify.com 即可。

## 小贴士（来自一位资深设计师的建议）

- 作品宁缺毋滥，3 个讲透的项目胜过 10 个走马观花。
- 每个项目回答「so what」——你的判断带来了什么结果，尽量有数据。
- 在 AI 时代，把「你如何驾驭 AI 提效」也作为一个亮点呈现。
