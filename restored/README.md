# Restored portfolio

Recovered from the previously hosted static portfolio source:

- `index.html`
- `app.js`
- `styles.css`
- `vercel.json`

## Preview

From the repository root:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/restored/`.

## Privacy and assets

- The page uses `noindex,nofollow,noarchive` to discourage search indexing.
- Four core case studies are restored from the 16 supplied images.
- The original finance-proof section and three “more work” cards remain hidden because their source images were not included. This avoids broken images and prevents accidental publication of personal trading, exam, or internal-document screenshots.
